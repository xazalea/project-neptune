project: neptune

WASM Unikernel / Browser Proxy

1. Build: python3 build.py
2. Serve: python3 server.py
3. Open the cartridge below with a target URL

Direct link: neptune.svg?url=https://example.com

The SVG is a self-contained "cartridge" that bootstraps a WASM unikernel, registers a Service Worker, and proxies the target site through a local tunnel with HTML rewriting.
