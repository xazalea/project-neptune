project: neptune

WASM Unikernel / Browser Proxy v3.0.0 Zero External Servers

example.com neverssl.com httpbin.org info.cern.ch
1. Build the cartridge: python3 build.py
2. Serve locally: python3 server.py
3. Open neptune.svg?url=TARGET in any modern browser

Neptune is a self-contained SVG "cartridge" that bootstraps a WASM unikernel, registers a Service Worker kernel, and proxies any target site through a local tunnel with full HTML rewriting, tracker blocking, and anti-fingerprinting.

🔬
SW Proxy
Cross-origin fetch & rewrite via ServiceWorker
🛡
Anti-Track
Fingerprint randomization per session
🌐
WASM TCP/IP
smoltcp stack with fetch() bridge
📄
Local Rewrite
Drag/drop or paste HTML — no network
