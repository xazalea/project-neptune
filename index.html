How to Use

1. Type a URL above and press Enter or click Go.
2. The proxy fetches the site, rewrites all links to stay inside the proxy, and loads it in a tab.
3. Use the toolbar for back/forward, bookmarks (Ctrl+D), reader mode, network inspector, and more.
4. Drag & drop an HTML file or paste raw HTML for offline rewriting.

How It Works

Neptune is a self-contained SVG cartridge — zero external servers, zero browser extensions.

A ServiceWorker intercepts navigation requests and fetches the real cross-origin target. Because SWs are trusted browser contexts, they bypass CORS for navigation responses.

All HTML, CSS, and JS URLs are rewritten to route through the proxy path, keeping every resource same-origin.

For sites that block direct fetch, an iframe visual proxy loads the target in a sandboxed frame.

A WASM TCP/IP stack (smoltcp) runs entirely in-browser with a fetch()-based Ethernet bridge — no relay servers.

Privacy & Features

● Anti-fingerprinting — Canvas, WebGL, AudioContext, and navigator spoofing injected into every proxied page.

● Tracker blocking — Pattern-matches known analytics, ad, and tracking domains.

● Cookie jar — Per-domain simulated cookies stored locally, never sent to external servers.

● Traffic obfuscation — Randomized header profiles and timing jitter.

● All data stays local — Bookmarks, history, and settings are stored in your browser only.
