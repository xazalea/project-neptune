  The cartridge is a SINGLE FILE:
    neptune.svg  — embeds SW + WASM JS glue + WASM binary + Network Adapter

  Fully standalone — zero proxy servers, zero extensions, zero external URLs:
    - ServiceWorker kernel: intercepts & proxies all requests
    - smoltcp WASM TCP/IP stack: in-browser networking stack
    - Network Adapter: fetch()-based Ethernet bridge (zero relay servers)
    - Fingerprint Engine: anti-fingerprinting randomization injected into pages
    - Direct fetch: SW fetches cross-origin, rewrites HTML, strips trackers
    - iframe visual proxy: browse sites that block direct access
    - Local HTML rewrite: drag/drop or paste HTML files → WASM processing

  How it works:
    ServiceWorkers are trusted browser contexts. They CAN fetch
    cross-origin URLs and read response bodies when responding to
    navigation events. The SW rewrites all resource URLs to go
    through the proxy path, keeping everything same-origin.

  smoltcp + Network Adapter (zero-relay networking):
    Rust TCP/IP stack (smoltcp) → Ethernet frame → JS callback →
    Network Adapter parses ARP/IP/TCP → SW postMessage →
    SW fetch() → Internet → SW postMessage → feed back to smoltcp

  To run locally:
    python3 server.py
    http://localhost:8080/neptune.svg

  To deploy to GitHub Pages / jsDelivr:
    git add neptune.svg && git commit && git push
    The SVG is self-contained — no other files needed
